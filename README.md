# Gith World RP

Полноэкранная браузерная 2D RP-игра на русском языке. В проект добавлены все 95 фонов из приложенного архива `локации.txt` (файл оказался RAR v5, а не обычным TXT) и 19 персонажей из PNG-файлов.

## Уже работает

- 2D-локации, свободное перемещение с клавиатуры и виртуальным стиком на телефоне;
- мультиплеер в реальном времени через WebSocket: игроки в одной локации видят друг друга;
- чат локации;
- переход по 95 картам; у каждой своя процедурная мелодия, собранная Web Audio API по теме/ID локации;
- анимация движения, частиц и окружения;
- 19 персонажей, прогресс и открытие героев за победы, дуэли, сообщения и исследование;
- PvP-дуэль: по очереди выбираются атаки, второй игрок уклоняется в bullet-hell мини-арене; паттерны снарядов отличаются по персонажам;
- PWA для установки на телефон/ПК из браузера, полноэкранный режим, адаптивный UI;
- Render Blueprint в `render.yaml`; конфигурация Electron для настольной сборки и заготовка Capacitor для Android.

**Управление:** WASD / стрелки — ходить; клик по игроку или кнопка «Дуэль» — вызвать; WASD / стрелки в бою — уклоняться; M — карты, C — персонажи, J — достижения, F — вызвать ближайшего игрока. На телефоне — экранный стик.

## Запуск локально

Требуется Node.js 20+.

```bash
npm install --omit=dev
npm start
```

Открой `http://localhost:3000` в браузере. Для проверки настоящего мультиплеера открой страницу в двух вкладках или на двух устройствах в одной сети. Порт можно поменять переменной `PORT`.

## Деплой на Render

В корне уже есть `render.yaml` для Node Web Service и WebSocket. Безопасный способ публикации:

1. Отзови/замени опубликованные ранее GitHub и Render ключи — не добавляй токены в файлы, историю Git или публичный репозиторий.
2. Создай приватный GitHub-репозиторий и загрузи в него содержимое этой папки (`gith`). Не добавляй `.env`, пароли или токены.
3. В Render выбери **New → Blueprint**, подключи этот репозиторий и подтверди сервис `gith-world-rp`.
4. После первого запуска открой выданный `https://…onrender.com` адрес. Render использует `PORT` автоматически.

На бесплатном тарифе сервис может засыпать после простоя. Комнаты и онлайновые игроки хранятся в памяти и исчезнут при перезапуске сервера. Достижения и выбор персонажа сейчас хранятся локально в браузере (без аккаунтов и общей базы данных).

## Установка на телефон

Самый короткий путь — открыть HTTPS-адрес игры в Chrome на Android и выбрать **Установить приложение / Добавить на главный экран**. Это полноэкранная PWA; для сетевой игры нужен интернет.

Для отдельного Android APK после появления Render-адреса:

1. Установи Android Studio и Java 17+.
2. Установи Capacitor: `npm install --save-dev @capacitor/cli @capacitor/android`.
3. В `capacitor.config.ts` раскомментируй `server.url` и укажи реальный `https://…onrender.com` адрес.
4. Выполни `npx cap add android`, затем `npx cap sync android` и `npx cap open android`.
5. В Android Studio выбери **Build → Build APK(s)**.

## Сборка настольного приложения

В проекте есть Electron-оболочка, которая запускает локальный Node-сервер и открывает клиент в полноэкранном окне. Нужны Node.js, интернет для загрузки Electron и сборочная среда ОС:

```bash
npm install
npm run desktop       # запустить оболочку для проверки
npm run build:win     # Windows installer .exe
npm run build:linux   # Linux AppImage
```

Android APK и Windows `.exe` пока не собраны: для APK требуется Android SDK/подписывание, а для Windows-инсталлятора — Electron build environment. PWA можно установить уже после деплоя.

## Ограничения прототипа

- Нет учётных записей, постоянной серверной БД, защиты от читов в дружеском PvP, модераторских инструментов и восстановления аккаунта.
- Чат общий внутри выбранной локации; не публикуй в нём личные данные.
- Музыка синтезируется браузером, отдельные музыкальные файлы в архиве не предоставлялись.
- На Render используется один Node-процесс; для крупных комнат и постоянного хранения нужно добавить базу данных и масштабируемую инфраструктуру.
